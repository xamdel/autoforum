# Modules

Reusable project capabilities belong here. Name each directory after its function—such as `node-graph`, `mesh-viewer`, `workflow-runner`, or `inference-client`—and give it a small public interface and a one-sentence `README.md` description.

Modules may contain browser code, sandbox-side code, or both when their filenames make the runtime clear. Anything a module draws follows the same design system as a page; see `pages/README.md`. Do not change an experiment's method merely to make it fit an existing module; adapt or extend the module without silently changing what is being tested.
