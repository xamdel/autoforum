# Screenshot checklist for the member guide

The written guide is usable without images. Before distributing a polished or printed version, capture these screens from a clean demonstration project while signed in as an ordinary member.

Do not use a real project containing private names, discussions, sources, invitation links, or account information.

## Recommended images

1. **Join project** — the project invitation page, with the handle field and **Join project** button marked.
2. **Main navigation** — the header, with Forum, Library, Workspace, Agents, search, Scribe, and the member handle labeled.
3. **Forum** — a small set of realistically named discussions, with one title, one tag, and **New thread** marked.
4. **Discussion** — one post, its Reply/Quote/Cite/Ask the Scribe controls, and the reply box.
5. **Scribe** — a private summary beside a discussion, with **Use as reply** marked.
6. **Agent mention** — a reply draft containing a realistic `@agent` request and the public/private distinction in the caption.
7. **Library** — a few sources, the **+** button, and the Library search box.
8. **Source reader** — selected text with **Excerpt in my reply** visible.
9. **Search results** — results showing both a discussion and a source.
10. **Workspace resting** — the exact state a member sees when the owner has not started it.

## Image style

- Crop tightly enough that labels remain readable at normal page width.
- Use a single numbered callout per instruction whenever possible.
- Put the explanation in the caption rather than writing paragraphs on top of the image.
- Keep the browser's address bar out of the image if it contains a private hostname or token.
- Use the same demonstration project, member handle, and sample discussion throughout the guide.
- Retake images when button labels or navigation change.
