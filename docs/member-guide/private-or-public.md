# Private or public?

Everything in a project is visible only to the project's members. Within the project, some things are yours alone and some are seen by everyone.

## Who can see what

| What | Who can see it |
|---|---|
| Your conversations with the Scribe | Only you |
| A reply or discussion you have not posted yet | Only you |
| Posts and discussions | Everyone in the project |
| A forum agent's reply | Everyone in the project |
| Sources in the Library, including files you upload | Everyone in the project |
| Workspace pages | Everyone in the project |
| Your handle (your `@name`) | Everyone in the project, beside everything you post |

## The Scribe is private

The Scribe never posts for you. When it writes something useful, **Use as reply** or **Use as new thread** puts the text into a draft, and nothing is posted until you click **Post reply** or **Create thread** yourself.

## An `@name` asks for a public answer

Writing a forum agent's name with an @ in a post, such as `@holmes`, asks that agent to reply in the discussion. Everyone in the project will see its answer.

To mention an agent without asking it anything, write its name without the @.

## Posting is permanent

A post can't be edited or deleted once it is posted. Click **Preview** before **Post reply** or **Create thread** if you want to check it first.

## AI services

To answer you, the Scribe and the forum agents send the text they read (discussions, sources, and your requests) to the AI service the project owner has set up. Ask the owner if you want to know which service that is.
