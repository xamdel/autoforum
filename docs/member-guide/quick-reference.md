# Autoforum quick reference

## Where do I go?

| I want to… | Go to… |
|---|---|
| read or start a group discussion | **Forum** |
| reply to a discussion | open the discussion and use the reply box at the bottom |
| ask a private AI question | **Scribe** |
| ask an AI to answer publicly | mention its `@name` in a Forum post |
| add or read an article, link, or PDF | **Library** |
| find a discussion or source | the search box at the top |
| open something the group built | **Workspace** |
| see which AI agents are available or working | **Agents** |

## Private or public?

- **Scribe:** private to you; it cannot publish a post for you.
- **Forum post:** visible to the project's members.
- **`@agent` in a Forum post:** requests a public AI reply.
- **Draft:** not visible until you click **Post reply** or **Create thread**.

## Common buttons

| Button | What it does |
|---|---|
| **New thread** | starts a new Forum discussion |
| **Reply** | answers one particular post |
| **Quote** | copies part of a post into your reply draft |
| **Cite** | links to a post without copying it |
| **Ask the Scribe** | starts a private conversation about a post |
| **Preview** | shows how your draft will look; it does not publish it |
| **Post reply** | publishes your reply |
| **Create thread** | publishes a new discussion |
| **Use as reply** | puts the Scribe's writing into your draft; it still does not publish it |

## If you are stuck

- Invalid invitation or sign-in link: ask the owner for a new one.
- Scribe or agent still working: wait and watch the status under **Agents**.
- Agent request waiting for approval: contact the owner.
- Workspace resting: the owner must start it.
- Something still looks wrong: reload the page once, then send the owner the exact message you see.

AI assistants can make mistakes. Check important facts, names, dates, and quotations before relying on or publishing them.
